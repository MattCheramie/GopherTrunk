## Reddit — body

```markdown
**[GopherTrunk](https://gophertrunk.org) v0.2.8 is out** — pure-Go digital-trunking scanner for RTL-SDR / HackRF / Airspy. P25 (Phase 1+2), DMR (AMBE+2 voice), NXDN, Motorola Type II, EDACS, LTR, MPT 1327, dPMR, D-STAR, YSF, plus APRS, POCSAG paging, AIS / DSC / ADS-B. No CGO, single static binary for Linux / macOS / Windows.

**What's new since v0.2.7:**

* **P25 control channel: ~3× the signalling** (#470, issue #402) — a P25 data unit packs up to three TSBK blocks after one FSW + NID, but the decoder only ever read the first, silently dropping ~2/3 of a busy site's grants / affiliations / status broadcasts. It now decodes every block, resuming across receive batches. On the MMR Site 9 capture: 14 → 41 CRC-clean TSBKs in ~1 s.
* **`replay` channel tuning for off-centre captures** (#470, issue #402) — `-tune-hz` / `-auto-tune` frequency-shift a recorded wideband IQ file so an off-centre control channel lands at 0 Hz before the demodulator, the way the SDR tuner does live. A channelised slice of the real Site 9 control channel ships as a decode regression fixture.
* **Hide unused UI tabs** (#474, closes #455) — set a key to `false` under `web.tabs` to drop it from the nav strip in both the web console and the terminal TUI. Running for a single task? Declutter the nav. Routes stay mounted; it's nav-only hiding.
* **#402 DC-spike / asymmetric-eye investigation, continued** (#453, #459) — corrected the complex-LMS equalizer weight-update conjugation, and added diagnostics localizing the outer-rail symbol spread to multipath inter-symbol interference.

**Downloads** (Linux / macOS / Windows, x64 + ARM64): https://github.com/MattCheramie/GopherTrunk/releases/tag/v0.2.8

**Docs:** https://gophertrunk.org

Heads-up: the v0.x line is still flagged prerelease — actively developed, feedback / captures / bug reports very welcome.
```
