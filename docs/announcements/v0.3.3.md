## Reddit — body

```markdown
**[GopherTrunk](https://gophertrunk.org) v0.3.3 is out** — pure-Go digital-trunking scanner for RTL-SDR / HackRF / Airspy. P25 (Phase 1+2), DMR (AMBE+2 voice), NXDN, Motorola Type II, EDACS, LTR, MPT 1327, dPMR, D-STAR, YSF, M17, plus APRS, POCSAG + FLEX paging, and AIS / DSC / ADS-B. No CGO, single static binary for Linux / macOS / Windows.

**What's new since v0.3.2:**

* **P25 linear/CQPSK path now decodes real C4FM control channels** (#532, #529, issue #492) — the symbol-spaced CMA equaliser is replaced with a T/2 fractionally-spaced blind equaliser that synthesises the receive matched filter implicitly, opening both the simulcast multipath ISI and the C4FM-vs-RRC pulse-shape mismatch the old one-sample-per-symbol equaliser couldn't touch. Plus the coarse carrier seed is now gated on multipath, so a deep simulcast spectral null no longer reads as a spurious carrier offset that pins the Costas loop. Result: locks and decodes all 8 real P25 C4FM captures (0/8 before any fix).
* **DMR Tier II Voice LC Headers decode off-air** (#527) — the BPTC(196,96) / RS(12,9) / embedded-LC FEC layers are reworked to the canonical ETSI TS 102 361-1 layout (cross-checked against the MMDVM / dmr_utils references), so real Tier II signals stop streaming `decode.error`. A golden test pins the on-air bit ordering against a spec-literal encoder.
* **RTL-SDR Blog V4 (R828D) recovery** (#528, issue #264) — a new `sdr tuner detected` diagnostic reports the tuner chip, Blog V4 state, and effective reference crystal (16 MHz = auto-detect missed; 28.8 MHz = V4 path armed), and per-device `blog_v4` / `blog_v4_lite` config keys force V4 mode when USB-string auto-detection misses the unit.
* **Signal Lab web UI + offline API** (#530) — `siglab` gains a standalone React SPA: upload or synthesise a capture, run the engine with a live event stream, and inspect constellation / eye / histogram / spectrogram / sync-landscape views, plus a compare workspace that diffs captures against each other or an idealised reference. Served by a new offline `/api/v1/siglab/*` API and a daemon-free `gophertrunk siglab serve` command.

**Downloads** (Linux / macOS / Windows, x64 + ARM64): https://github.com/MattCheramie/GopherTrunk/releases/tag/v0.3.3

**Docs:** https://gophertrunk.org

Heads-up: the v0.x line is still flagged prerelease — actively developed, feedback / captures / bug reports very welcome.
```
