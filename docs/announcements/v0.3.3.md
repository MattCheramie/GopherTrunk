## Reddit — body

```markdown
**[GopherTrunk](https://gophertrunk.org) v0.3.3 is out** — pure-Go digital-trunking scanner for RTL-SDR / HackRF / Airspy. P25 (Phase 1+2), DMR (AMBE+2 voice), NXDN, Motorola Type II, EDACS, LTR, MPT 1327, dPMR, D-STAR, YSF, M17, plus APRS, POCSAG + FLEX paging, and AIS / DSC / ADS-B. No CGO, single static binary for Linux / macOS / Windows.

**What's new since v0.3.2:**

* **SigLab in the browser** (#530) — a standalone, daemon-free single-page Signal Lab app that visualises one or more captures, served by a new offline signal-analysis HTTP API (`siglab serve`). Backed by an in-memory decode path (analyse a capture straight from any reader — synthesised signal or HTTP upload — no disk round-trip) and bounded decimated-IQ taps.
* **RTL-SDR Blog V4 diagnostics + manual override** (#528, issue #264) — a new "sdr tuner detected" log line reports the tuner chip, V4 state, and effective reference crystal (16 MHz on an R828D = auto-detect missed), and per-device `blog_v4` / `blog_v4_lite` keys force V4 mode regardless of EEPROM strings.
* **DMR Tier II Voice LC Headers decode off-air** (#527) — the BPTC(196,96) / RS(12,9) FEC layers were reworked to the canonical ETSI / MMDVM bit layout, so real off-air Voice LC Headers decode instead of erroring at the `voiceheader-bptc` / `voiceheader-rs` stages.
* **P25 CQPSK finally locks on real C4FM** (#529, #532, issue #492) — a multipath-gated carrier seed stops a simulcast spectral null from faking a carrier offset, and a new T/2 fractionally-spaced blind equaliser opens the C4FM-vs-RRC pulse mismatch the symbol-spaced equaliser couldn't. CQPSK lock went 0/8 → 8/8 across the reporter's stress captures.
* **Decoder live-capture requirements summary** (#526) — a per-decoder catalogue of which decoders still need real over-the-air captures to be fully validated, with format / sample rate / modulation / acceptance criteria.

**Downloads** (Linux / macOS / Windows, x64 + ARM64): https://github.com/MattCheramie/GopherTrunk/releases/tag/v0.3.3

**Docs:** https://gophertrunk.org

Heads-up: the v0.x line is still flagged prerelease — actively developed, feedback / captures / bug reports very welcome.
```
