## Reddit — body

```markdown
**[GopherTrunk](https://gophertrunk.org) v0.3.4 is out** — pure-Go digital-trunking scanner for RTL-SDR / HackRF / Airspy. P25 (Phase 1+2), DMR (AMBE+2 voice), NXDN, Motorola Type II, EDACS, LTR, MPT 1327, dPMR, D-STAR, YSF, M17, plus APRS, POCSAG + FLEX paging, and AIS / DSC / ADS-B. No CGO, single static binary for Linux / macOS / Windows.

**What's new since v0.3.3:**

* **High-bit-depth network SDRs via SoapyRemote** (#541, #543) — a new pure-Go (zero-CGO) `soapyremote` backend connects to a remote `SoapySDRServer` and mounts it as a virtual tuner alongside local USB dongles and `rtl_tcp` endpoints. Unlike `rtl_tcp`'s hardcoded 8-bit stream it carries the full dynamic range of high-end radios — USRP, LimeSDR, bladeRF, HackRF, Airspy, RTL-SDR, SDRplay — as 16-bit (`CS16`) or 32-bit float (`CF32`) IQ, with native frequency / sample-rate / gain control. Configure under `sdr.soapy_remote`.
* **`gophertrunk capture` — record raw IQ off a live SDR** (#540) — a first-class subcommand that opens a dongle directly (no daemon) and records N seconds of raw IQ to a GNU Radio `.cfile` (or rtl_sdr-native `u8`) plus a siglab metadata sidecar, so the capture is a drop-in fixture for `replay` / `analyze` / `test`. The SigLab web console gains a matching "Capture from tuner" control with a browser download.
* **RTL-SDR Blog V4 (R828D) deafness fixed** (#535, #538, issue #264) — two independent R828D bugs that left the V4 deaf where an R820T2 decoded cleanly: an inverted mixer-AGC bit + unwritten VGA in `SetGainMode` (the front end ran well below its intended gain in AGC mode), and the wrong PLL VCO power reference (2 instead of the fork's 1 for the R828D, mistuning the LO).
* **P25 decode-lag fix** (#534, #537, issue #492) — now that the new fractionally-spaced equaliser lets CQPSK lock, the BCH(63,16) NID error-corrector — which brute-forced all 65,536 codewords on every call and stalled the pipeline for seconds — is rewritten as an algebraic Berlekamp-Massey / Chien decoder. Decode outcomes are identical (proven against a brute-force oracle); the hot path drops from ~1 ms to microseconds.
* **DMR Tier II Voice LC Header FEC verified vs MMDVM + off-air diagnostics** (#539) — RS(12,9) cross-checked against an independent reference encoder (confirming it matches the MMDVMHost convention), plus burst-level debug logging so a real failing off-air burst can be localised.

**Downloads** (Linux / macOS / Windows, x64 + ARM64): https://github.com/MattCheramie/GopherTrunk/releases/tag/v0.3.4

**Docs:** https://gophertrunk.org

Heads-up: the v0.x line is still flagged prerelease — actively developed, feedback / captures / bug reports very welcome.
```
