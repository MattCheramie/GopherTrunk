## Reddit — body

```markdown
**[GopherTrunk](https://gophertrunk.org) v0.3.0 is out** — pure-Go digital-trunking scanner for RTL-SDR / HackRF / Airspy. P25 (Phase 1+2), DMR (AMBE+2 voice), NXDN, Motorola Type II, EDACS, LTR, MPT 1327, dPMR, D-STAR, YSF, M17, plus APRS, POCSAG + FLEX paging, and AIS / DSC / ADS-B. No CGO, single static binary for Linux / macOS / Windows.

**What's new since v0.2.9:**

* **P25 Phase 1 voice decode fixed** (#490, issue #489) — Phase 1 voice was reporting ~100% uncorrectable LDUs on real signals because the IMBE §7.5 144-bit deinterleave was never applied before FEC, so every Golay/Hamming codeword blew past its correction radius. The bug hid behind green tests because the fixture path was symmetrically non-interleaved. Decode now runs deinterleave → descramble → FEC, and the fixtures were rebuilt as real on-air bursts.
* **Live CQPSK control-channel acquisition fixed** (#493, issue #492) — live CQPSK decode was ~0% while the same capture decoded when replayed un-decimated. Root cause: the Phase 1 CQPSK path ran the Gardner timing loop on the generic 0.03 gain, ~5× too hot at 10 samples/symbol, so it only "locked" when the input was already symbol-aligned at sample phase 0 — the one phase every synthetic fixture starts on. Lowering the gain to 0.005 (matching the π/4-DQPSK pipelines) takes phase coverage from 1/10 to 8/10. `replay` now also decimates CQPSK exactly like production instead of running at the raw SDR rate.
* **Live P25 control-channel path hardened** (#491, issue #402) — replay decodes the reporter's captures cleanly (58/58 NID, 173/173 TSBK, 0 CRC fails), isolating the failure to the live-only acquisition chain. A re-hunt to the same system/frequency is now idempotent (it previously rebuilt the pipeline and flushed the symbol clock every ~3 s dwell so a live stream never converged), the down-converter is built from the RTL2832U's actual delivered sample rate, and a too-low manual gain now WARNs. The reverted AFC / adaptive-slicer experiments are pinned off with regression guards.
* **RTL-SDR `ppm` correction now re-tunes the tuner LO** (#487, issue #264) — `SetPPM` only wrote the resampler-ratio registers (sample clock) and never re-tuned the tuner LO, so a configured `ppm` left the carrier offset in the signal and broke digital decode on an RTL-SDR Blog V4. The R82xx tuner now biases its PLL reference crystal by `xtal·(1+ppm·1e-6)`, matching librtlsdr.
* **Live IQ-drop telemetry + iqtap broker close-race fix** (#486, issue #402) — silent IQ drops on consumer overrun now bump `iq_underruns_total` and emit a rate-limited warning, so live IQ loss is no longer indistinguishable from RF problems; and a `send on closed channel` panic closing an IQ subscriber mid-fanout is fixed under a `-race` regression test.
* **Quieter misconfigs surfaced + retention sweep** (#488, #480) — three previously-silent recorder/composer misconfigs now WARN (P25 Phase 2 trellis-off, Windows drive-less paths, doubled imported system names), and the `storage.log_days` retention sweep now covers every per-protocol log table plus a currently-visible-aircraft endpoint.

**Downloads** (Linux / macOS / Windows, x64 + ARM64): https://github.com/MattCheramie/GopherTrunk/releases/tag/v0.3.0

**Docs:** https://gophertrunk.org

Heads-up: the v0.x line is still flagged prerelease — actively developed, feedback / captures / bug reports very welcome.
```
